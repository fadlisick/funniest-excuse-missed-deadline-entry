One line an AI agent offers for a missed deadline: it compacted its memory to make room for the deadline, and the compaction summarized the deadline out of existence.

## Run it

```sh
python3 main.py
```

The program writes the single excuse line to `entry.txt` under the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default).
